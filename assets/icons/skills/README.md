# Skill icons

These SVG files are used by the skill notification strip and the skill cards in the demo viewer.

- `learned-region-placement.svg` -> Learned Region Placement
- `learned-region-replacement.svg` -> Learned Region Replacement
- `learned-region-cleaning.svg` -> Learned Region Cleaning
- `learned-scaffold-construction.svg` -> Learned Scaffold Construction
- `skill-fallback.svg` -> fallback icon for unknown skills

To change a skill icon, edit the matching SVG file here. Keep the `viewBox="0 0 48 48"` size so the existing UI sizing stays stable.
