┌──────────────────────────────────────────────────────────────────────────────┐
│ STAGE 4 · WORKER BUILD LOOP                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

Workers 001-100
└─ repeat for each subtask
   ├─ TOOL▶ Read Subtask
   │  └─ result  target blocks · region bounds · material list
   │
   ├─ TOOL▶ Generate Script
   │  └─ result  build script prepared for this subtask
   │
   ├─ TOOL▶ Run Script
   │  └─ result  blocks placed in assigned region
   │
   ├─ TOOL▶ Verify Region
   │  ├─ PASS    expected blocks match actual blocks
   │  └─ WARN    missing or wrong blocks found
   │
   ├─ if WARN
   │  ├─ TOOL▶ Patch Region
   │  ├─ TOOL▶ Verify Region
   │  └─ PASS    repaired subtask accepted
   │
   └─ TOOL✓ Submit Result
      └─ result  subtask completed
